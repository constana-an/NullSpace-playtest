# NULL SPACE — 试玩包

第一人称空间解谜游戏的内部试玩版本。下载见右侧 **Releases**。

## Windows 怎么玩

1. 在 Releases 里下载 `NullSpace-Windows.zip`。
2. **完整解压**到一个文件夹（不要在压缩包里直接双击）。
3. 双击 `NullSpace/NullSpace.exe`。`NullSpace_Data`、`UnityPlayer.dll`、`MonoBleedingEdge` 等要和 exe 放在一起。
4. 第一次运行如果弹出"Windows 已保护你的电脑"：点 **更多信息 → 仍要运行**（游戏没有数字签名）。

## 操作

- WASD 移动，鼠标看，空格跳，E 交互，Esc 暂停菜单（设置在这里，可调鼠标灵敏度、画面、改键）
- Q 旋转房间（滚轮或 A/D 选方向，R 或左键确认）
- C 连接红框门，Tab 扫描器，F 折叠（第 3 章），Backspace 重置当前谜题

## 反馈

玩完（或者遇到闪退、黑屏、卡住）请把日志发回来：

`%USERPROFILE%\AppData\LocalLow\NullSpace\NULL SPACE\Player.log`

把这串路径粘贴到资源管理器地址栏即可打开（AppData 是隐藏文件夹）。日志里只有游戏内的操作记录。
